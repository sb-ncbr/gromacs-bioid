# Beyond-GT measurement handoff (§3.4 backing) — beyond_gt_v14

## Core Concept
How the "beyond deposited annotations" (manuscript §3.4, Fig. 4) numbers were measured and what traps they contain. Pipeline: `scripts/stats/beyond_gt_v14.py` (canonical local copy), run 2026-10-12 read-only on cluster; artifacts `journal/draft/data/beyond_gt_v14{,_rows,_elements}.json(l)`. Final text + captions: `journal/draft/pending-edits-2026-10-09.md` §10–§11; `manuscript.md` §3.4 rewritten. Ledger: `publication-journal.md` 2026-10-12 entries.

## Key Points
- **Headline**: 2,403/14,616 gate-pass deposits (16.4%) hold ≥1 verified organic identity with NO composition-level counterpart in the deposit's own metadata GT. Classes (overlap per deposit): other small molecules 1,354 · generic-resname ligands 745 · membrane lipids 433 (428 formula + 5 resname) · cofactors/nucleotides 83 · glycans 29 · buffers 2.
- **Metals claim INVERTED by data**: Zn 195 / Mg 176 / Ca 139 / K 380 bearing deposits — GT lists metal on all but 6 (Zn). Chloride present-but-unlisted on 934 of 1,378 Cl-bearing deposits (68%). "Salt/lipid/cofactor gap, not metallobiology".
- **Guards that made it honest** (burned-in traps, never quote raw joins): (1) 37,777 hits were protonation/stereo state-siblings of GT-listed compounds (44% of pre-guard "beyond ATP") → beyond requires BOTH InChIKey connectivity-block AND H-stripped heavy-atom formula absence; (2) 18,457 verified chem hits on protein segments are amino-acid sidechain artifacts (~9.8% of all chem verified hits) → excluded by segment frag type; (3) element presence must be deduped PER DEPOSIT across prot/mixed/free buckets (naive sum gave Cl 1,474; correct 1,378); (4) sodium invisible — engine emits 'NA='-style tokens the `^[A-Z][a-z]?=[0-9]+$` fragment-key parser never captures (Na measured 50 vs Cl 1,378 is an artifact).
- **Wording constraints (author-locked)**: 93 chem annotations = "no usable ligand evidence" (75 unparsesable + 18 no ligand), NOT "no ligand in box"; 531 protein annotations = 530 membrane-only + 1 nucleic-only (A5/S0-OQ-1); ghosts 7,298 ids / 6,782 pairs / 6,629 re-resolved (153 dead both sides, 645 cid:0); refusal 334 of 15,185 loading-class (v14 taxonomy; 437/708 v13 framing dropped by author).
- Exemplars verified end-to-end: deposit 2364 (6 GT ligands + 64 PI lipids beyond), 4341 (Zn+ligand GT + 76 Tris records), 7711 (1 GT ligand + 13 SAH records).

## Details
- Pipeline: `scripts/stats/beyond_gt_v14.py` phases `scan` (runs on deploy/validation-api, NFS `/data/validation/`; worker OOMs) and `join` (runs on deploy/bat3-ceitec-bat3-worker, PubChem mirror only there). v5 = sibling guard + prot-seg exclusion + GENERIC_RESNAMES→ligand_generic + COFACTOR/CARBO/BUFFER enriched vocab.
- Anchors: 15,133 result dirs → 14,616 gate-pass (load+analyze OK); 26,368 segments ✓; verified totals PROT 838,809 / CHEM 187,638. GT: postgres `bat3_validation.ground_truth_signatures` (2026-10-07 harvest; 14,943 entries; 7,342 with chem GT; counters 9,626/12,541/14,787).
- Mirror: `/app/databases/pubchem/v2026-10-07/pubchem.sqlite` (the `current` symlink dir holds only build_metadata.json); schema `compounds(cid, smiles, inchikey, formula_hill, exact_mass)`, idx_inchikey, NO names table → labels from resname generator. 78,638 distinct verified CIDs, 99.96% mirror-resolved; 4,311 distinct GT InChIKeys (3,964 formula-resolved = 92%; unformulated GT can't formula-guard).
- results.json schema gotchas: verified hits at `data.verification.<seg>.verified_hits[{ident_type, identifier, is_verified, final_confidence}]`; ident_type census PDB_ID/PUBCHEM_CID/UNIPROT_ID/SWISSPROT_ID/CHEMBL_ID/CHEBI_ID/INCHIKEY — **no ION type** (ions are presence-scored only). CHEMBL/CHEBI ids unjoinable to mirror (beyond-GT chem = CID+INCHIKEY lanes only → lower bound). Fragment keys carry no ion atoms for PDB-style deposits → ion presence comes from element scan, not keys. `data.fragments.unique` reflects only parseable deposit content.
- Cluster ops: workers ephemeral — re-ship script via base64 each run; validation-api has DATABASE_URL (bat3_validation: mddb_entries id↔local_accession, ground_truth_signatures); cache `internalId` = ObjectId, not numeric dir id; rancher DNS flaky → retry loop.
- Pipeline follow-ups (engineering, not paper): (a) seg_kind filter for chem verification on protein segments (sidechain artifact channel, ~10% of chem verified hits); (b) parse two-letter 'NA='-style element tokens in fragment keys (Na detection); both from this measurement, user informed, Methods/limitations mention is an open author decision.
- Proteins excluded from beyond-GT BY DESIGN: identifier-string matching cannot express family-level verified homologs (would inflate false "beyond"). Protonation-safe at entry level; distinct-identity count (19,368) is state-inflated — quote entry counts only.
