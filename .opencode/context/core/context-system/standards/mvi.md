# Minimal Viable Information (MVI) Standard

## Core Concept
MVI ensures context files remain concise, scannable, and immediately useful. Every file must deliver maximum signal with minimum noise.

## Key Points
- **File size limit**: All files must be <200 lines
- **Structure**: Core concept → Key points → Minimal example → Reference
- **Purpose**: Enable rapid understanding without overwhelming detail
- **Verification focus**: Include only information needed to validate behavior

## Minimal Example

```markdown
## Core Concept
One to three sentences explaining the essential idea.

## Key Points
- Bullet 1: Key fact or rule
- Bullet 2: Another key fact
- Bullet 3: Important constraint
- Bullet 4: Critical dependency
- Bullet 5: Verification hint

## Reference
- Link to full documentation or source file
```
